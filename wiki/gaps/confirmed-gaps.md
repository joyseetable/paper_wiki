# Confirmed Gaps

Problems that 3+ papers acknowledge as unsolved. These are the most reliable starting points for new ideas.

## How to Use This File
- Each gap is a `##` section with evidence from papers
- Link to the papers that confirm the gap exists
- When a gap is solved, move it to the bottom under "Resolved"
